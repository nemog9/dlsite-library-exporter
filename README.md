# DLsite Library Exporter

DLsite の購入履歴（ボイス・コミック・CG など）を、[Hikidashi（引き出し）](https://nemog9.github.io/hikidashi-support/)に取り込める CSV にする、**iPhone（Safari）用のツール**です。PC のブラウザでも、ユーザースクリプトの拡張（Tampermonkey、Violentmonkey など）に入れれば動きます。

> 非公式のツールです。DLsite とは関係がありません。自分の購入履歴を、自分のブラウザの中だけで処理して、手元の CSV に保存するためのものです。外部のサーバーには、何も送りません。

出来上がった CSV は、iPhone アプリ [Hikidashi（引き出し）](https://apps.apple.com/jp/app/hikidashi-%E5%BC%95%E3%81%8D%E5%87%BA%E3%81%97/id6823911890) の「設定 → CSV をインポート」で取り込みます。
ページを 1 つずつ保存するなら、共有シートや Chrome 拡張 [Hikidashi クリップ](https://github.com/nemog9/hikidashi-clip)もあります。
DMM（FANZA）のマイライブラリを CSV にする、同じ作りのツール [DMM Doujin Exporter](https://github.com/nemog9/dmm-doujin-exporter) もあります。

## 書き出せるもの

購入履歴にある作品ごとに、次の内容が CSV に入ります。

| 内容 | 取得元 |
|---|---|
| タイトル | 作品情報（`【期間限定…円】` のようなセールの表記は取り除く） |
| URL | 作品ページ（`https://www.dlsite.com/maniax/work/=/product_id/RJ….html` の形） |
| クリエイター | サークル名 + 声優（なければ作者、イラスト、シナリオの順） |
| カテゴリ | ボイス・ASMR → `ボイス`、マンガ → `コミック`、CG・イラスト → `CG`、動画 → `動画`（それ以外は DLsite の作品形式名） |
| 画像 | 作品のメイン画像 |

## 📱 iPhoneで使う（Safari + Userscripts）

「Userscripts」は、Safari の中で、決めたサイトにだけ、小さなプログラム（スクリプト）を動かせる、無料のアプリ（拡張機能）です。

> 設定の画面の名前は、iOS のバージョンで、少し違うことがあります。**手順 2 の設定を、すべて済ませないと、動きません。** つまずきやすいので、順番どおりに進めてください。

### 手順 1　Userscripts アプリを入れて、保存フォルダを選ぶ
1. App Store で「[Userscripts](https://apps.apple.com/app/userscripts/id1463298887)」（作者: Justin Wasack、無料）を入れる。
2. **Userscripts アプリを、一度、開く。**
3. 「スクリプトの保存先フォルダ」を選ぶ（画面の案内に従う）。「ファイル」アプリの「このiPhone内」に、新しいフォルダ（例：`Userscripts`）を作って選ぶのが簡単です。

### 手順 2　Safari で、Userscripts を使えるようにする
1. 「**設定**」アプリ →「**アプリ**」→「**Safari**」→「**機能拡張**」→「**Userscripts**」を開く。
2. 「**拡張機能を許可**」を**オン**にする。
3. 「**他の Web サイト**」を「**許可**」にする。
   - 「確認」や「拒否」のままだと、DLsite のページで動きません。
   - 「すべての Web サイト」を許可したくない場合は、一覧で **`dlsite.com`（または `www.dlsite.com`）だけ**を「許可」にします。
4. 「プライベートブラウズ」ではなく、**通常のタブ**で開く。

### 手順 3　スクリプトを入れる
**A．URL から（簡単）**
1. Safari で、次の URL を開く（スクリプトの文字が、そのまま出ます）。
   `https://raw.githubusercontent.com/nemog9/dlsite-library-exporter/main/userscript/dlsite-export.user.js`
2. アドレスバーの左にある「**ページメニュー**」のアイコンをタップ →「**Userscripts**」を開く。
   - アイコンは、iOS 26 までは「**ぁあ**」（英語表示では「aA」）、**iOS 27 では、横線が 2 本、縦に並んだ（リーダーのような）アイコン**です。
3. 「**Install**」が出たら、タップする。出ない場合は B にしてください。

**B．ファイルで**
1. [Releases](https://github.com/nemog9/dlsite-library-exporter/releases/latest) から `dlsite-export.user.js` をダウンロードする。
2. 「ファイル」アプリで、手順 1 で選んだ保存フォルダに、移動する。
3. Userscripts アプリを開き、一覧に出ていることを確認する。

### 手順 4　購入履歴を開く
1. Safari で DLsite にログインし、マイページの「**購入履歴**」を開く（アドレスに `/mypage/userbuy` が入るページ）。
2. 画面の下に、青い枠の「**Hikidashi 書き出し（DLsite）**」のパネルが出れば、準備完了です。
   - **DLsite Play（`play.dlsite.com`）では動きません。** 購入履歴のページで使います。
   - 「デスクトップ用 Web サイトを表示」にする必要は、ありません。

### 手順 5　書き出す
1. **初回**は、パネルの「**全件・続きから**」をタップする。
2. 購入履歴の読み込み（50 件ずつ）→ 作品ごとの情報の取得の順に進みます。**進み具合と、残り時間**が出ます。
   - 目安は、**1,000 件で 25 分ほど**です。サイトに負荷をかけないよう、1 件ずつ、間隔を空けて読むため、ゆっくりです。
   - **終わるまで、Safari を前面に出したまま、画面を開いておいてください。** ほかのアプリに切り替えたり、画面をロックしたりすると、止まります。充電しながらの利用をおすすめします。
   - やめたいときは「中止」をタップします。**それまでに取れた分は、CSV に保存できます。**
3. 完了と表示されたら、「**CSV を保存**」をタップする（ダウンロードの確認が出たら「ダウンロード」）。保存先は、「ファイル」アプリの「ダウンロード」です。
4. Hikidashi を開き、「**設定 → CSV をインポート**」で、その CSV を選ぶ。

### 2 回目以降（新しく買った作品だけを足す）
1. 「**前回の CSV を選ぶ**」で、前回の CSV を選ぶ（Hikidashi から書き出した CSV でも、前回これで作った CSV でも構いません）。
2. 「**新着だけ**」をタップする。
   - 取得済みの作品が出てきたページで止まるので、通信は、数十回で済みます。
   - **お気に入り・メモ・非表示は、そのまま保たれます。**
   - 新しい作品は、**最後に買ったものが Hikidashi の一番上に来る順**で、CSV の末尾に追加されます。
3. 「CSV を保存」→ Hikidashi の「CSV をインポート」で取り込む。

### 途中で止まったとき
DLsite が応答を拒否したとき（HTTP 403 / 429 など）や、通信エラーのときは、**その場で止まり**、止まった理由を表示します。無理に続けたり、回避したりはしません。
- ここまでに取れた分は、「CSV を保存」で保存できます。
- 取得済みの作品は、この端末の Safari に覚えているので、**しばらく（数十分〜数時間）待ってから**、もう一度「全件・続きから」を押すと、**残りだけ**を取ります。

### うまくいかないとき

| 症状 | 確認すること |
|---|---|
| **パネルが出ない** | ① 「設定 → アプリ → Safari → 機能拡張 → Userscripts」が**オン**か。② 「**他の Web サイト**」が「**許可**」か（または `dlsite.com` が「許可」か）。③ **購入履歴**のページ（`/mypage/userbuy`）を開いているか（`play.dlsite.com` では出ません）。④ プライベートブラウズ**ではない**か。⑤ ページメニュー →「Userscripts」で、このスクリプトが**オン**か。⑥ ページを再読み込みする。 |
| 作品が 0 件 / 「見つかりませんでした」 | ログインしているか。購入履歴の一覧ページを開いているか。DLsite の画面の作りが変わった可能性があります（その場合は Issues へ）。 |
| 声優が空 | 声優が登録されていない作品（コミックや CG など）は、サークル名だけが入ります。ボイス作品で空の場合は、DLsite 側の仕様が変わった可能性があります。 |
| 「作品情報 … で止まりました」 | 上の「途中で止まったとき」を見てください。 |
| 「CSV を保存」を押しても、保存されない | ダウンロードの確認が出ていれば「ダウンロード」を選ぶ。「ファイル」アプリの「ダウンロード」を見る。それでも出なければ、「共有…」→「ファイルに保存」。 |
| 覚えている作品を消したい | パネルの「覚えた分を消す」を押す（次は、全件を取り直します）。 |

## 出力される CSV

Hikidashi に、そのまま取り込める CSV です（UTF-8 BOM 付き）。

```
"title","url","creators","thumbnail_url","category","note","favorite","hidden"
```

- `creators` は、`|` 区切りです。`note` と `favorite` / `hidden` は、新規分は空です（取り込み先の既存の値を保持）。
- **行の順番**: 前回の CSV の行は、そのまま先頭に置きます。新しい作品は、古い順にして、末尾に足します。Hikidashi は、CSV の行の順に番号を振るので、**最後に買った作品が、一番上に来ます**。

## 仕組みと、お願い

- 購入履歴の一覧ページ（`/mypage/userbuy/…/page/N`）を、順に読みます。
- 作品ごとの情報（声優、サークル、作品形式、画像）は、DLsite のサイトが使っている作品情報の JSON（`/api/=/product.json?workno=…`）から取ります。**これは、一般向けに公開されている API ではありません**（仕様が予告なく変わることがあります）。
- 負荷を抑えるため、**1 件ずつ、0.5〜1 秒の間隔**で読み、一覧のページも、約 1 秒おきに読みます。拒否されたら、その場で止まります。
- **初回以外は、「新着だけ」を使ってください。** 全件を何度も取り直さないでください。
- DLsite の利用規約を確認し、**自己責任**でお使いください。このツールで、作品のデータや画像を、再配布しないでください。

## プライバシー

- 取得した内容は、**ブラウザの中だけ**で処理して、CSV として手元に保存します。外部のサーバーには、何も送信しません。
- 通信するのは、ログイン済みのあなた自身の DLsite（`www.dlsite.com`）だけです。
- 「続きから」「新着だけ」のために、取得済みの作品の情報（タイトル、サークル、声優、画像の URL など）を、この端末の Safari の中（`localStorage`）に覚えます。消したいときは、パネルの「覚えた分を消す」か、Safari の Web サイトデータの削除を使ってください。

## 開発

- `userscript/dlsite-export.user.js` が、本体です（1 ファイルで動きます）。CSV の形式は、[dmm-doujin-exporter](https://github.com/nemog9/dmm-doujin-exporter) と同じです。
- `userscript/probe.user.js` は、作品情報の項目名などを調べるための診断用です（通常は使いません）。
